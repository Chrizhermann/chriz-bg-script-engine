## Decision

current lab. Permit downstream **shadow/pure policy development**, not a public installer,
automatic corpus enrollment, active dispatch or a migrated SCS family.

Evidence: [Task17](../../../../../docs/research/compatibility-lab-results.md) and
[Task16](../../../../../docs/research/KERNEL-01-integrated-observer.md). Real WeiDU refuses all four current
bridge publication collisions and preserves unrelated BCS/DLG/CRE bytes through the lifecycle.

an unenrolled controller advances public state during error/capability/disable/stale windows.
E2 rejects unknown identity, hashes, slots, dependencies, closure, public-state drift and duplicate
adapter IDs. Stale state never auto-reactivates. Kernel policy callbacks receive copied scalar
identities/snapshots, not native handles. Trusted EEex listener handlers remain native-boundary
code; this is not a sandbox for arbitrary third-party Lua.

The E4 fixture closure is authored/injected, not a real corpus scan. This gate cannot be used
as real-content activation evidence. Such activation still requires the exact later adapter
closure and G4/G5. No action dispatcher is exported by the observed kernel bundle.
